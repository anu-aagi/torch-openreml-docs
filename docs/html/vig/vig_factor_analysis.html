Factor Analysis of a Multi-Environment Trial¶

In a multi-environment trial (MET), the same genotypes are evaluated across several environments, resulting in correlated genotype-by-environment effects. An unstructured covariance matrix for \(m\) environments requires \(m(m+1)/2\) parameters (21 for \(m = 6\)). A factor-analytic (FA) structure reduces the number of parameters by representing the covariance through a small number of latent factors and environment-specific uniquenesses.

This vignette fits an FA(2) model to a simulated MET dataset, examining parameter recovery against the known generating values. It also demonstrates how the factor-analytic covariance is constructed from covariance classes and how its parameters are named. The analysis is then repeated on an unbalanced version of the trial, where each genotype is grown in only a subset of the environments.

The model¶

For genotype \(i = 1, \ldots, n\), environment \(j = 1, \ldots, m\) and replicate \(r = 1, \ldots, R\), write

\[y_{ijr} = \mu_j + g_{ij} + \varepsilon_{ijr}, \qquad \mathbf{g}_i = (g_{i1}, \ldots, g_{im})^\top \sim \mathcal{N}(\mathbf{0}, \boldsymbol{\Sigma}), \qquad \varepsilon_{ijr} \sim \mathcal{N}(0, \sigma^2).\]

The genotype-by-environment effects follow a factor-analytic covariance structure with \(k\) latent factors,

\[\boldsymbol{\Sigma} = \boldsymbol{\Lambda}\boldsymbol{\Lambda}^\top + \boldsymbol{\Psi}, \qquad \boldsymbol{\Psi} = \operatorname{diag}(\psi_1, \ldots, \psi_m),\]

where \(\boldsymbol{\Lambda}\) is the \(m \times k\) factor-loading matrix and \(\psi_j\) is the uniqueness of environment \(j\). Stacking the observations gives the linear mixed model

\[\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}\mathbf{g} + \boldsymbol{\varepsilon}, \qquad \mathbf{g} \sim \mathcal{N}(\mathbf{0}, \mathbf{G}), \qquad \mathbf{G} = \mathbf{I}_n \otimes \boldsymbol{\Sigma}, \qquad \mathbf{R} = \sigma^2 \mathbf{I}_N,\]

where

  • \(\mathbf{X}\) has one column per environment, with \(\boldsymbol{\beta}\) containing the environment means \(\mu_j\),

  • \(\mathbf{Z}\) maps each observation to its genotype-by-environment cell,

  • \(\mathbf{g}\) contains the cell effects,

  • \(\mathbf{I}_n \otimes \boldsymbol{\Sigma}\) specifies that the \(m\)-vector of effects for each genotype has covariance \(\boldsymbol{\Sigma}\), and that genotypes are independent.

See Introduction to Mixed Model REML Estimation for the general formulation of the mixed model and the REML estimator.

Identification¶

The decomposition \(\boldsymbol{\Sigma} = \boldsymbol{\Lambda}\boldsymbol{\Lambda}^\top + \boldsymbol{\Psi}\) is not unique, since orthogonal rotations of \(\boldsymbol{\Lambda}\) leave \(\boldsymbol{\Sigma}\) unchanged. To identify the factor loadings, we impose a lower-triangular constraint, setting \({\Lambda}_{ij} = 0\) whenever \(j > i\).

This constraint fixes the rotational indeterminacy, but the sign of each factor remains arbitrary. Consequently, estimated loadings may differ in sign from their generating values. The trial below illustrates these differences.

Specifying the covariance¶

The covariance of the genotype-by-environment cell effects is a sum of a rank-\(k\) term and a diagonal term. Gram with gram_type="xxt" turns the free loading matrix into \(\boldsymbol{\Lambda}\boldsymbol{\Lambda}^\top\), and LowerTriangularMatrix provides the free entries of \(\boldsymbol{\Lambda}\) with the upper triangle fixed at zero:

Z = DummyMatrix(genotype, environment)

k = 2

G = KroneckerProduct(
    genotype=IdentityMatrix(genotype),
    environment=Sum(
        factors=Gram(
            loadings=LowerTriangularMatrix(environment, k),
            gram_type="xxt",
        ),
        uniqueness=DiagonalMatrix(environment),
    ),
)

reml = MixedModelREML(g_by_e=(Z, G), R=ScalarMatrix(len(y)))

  • DummyMatrix builds the \(1200 \times 600\) incidence matrix with one column per genotype-by-environment cell.

  • LowerTriangularMatrix builds the \(6 \times 2\) lower triangular matrix with 11 free entries \(\lambda_{00}, \lambda_{10}, \lambda_{11}, \ldots, \lambda_{50}, \lambda_{51}\), and a structural zero in the upper triangle.

  • DiagonalMatrix supplies the six uniquenesses \(\psi_j\).

  • KroneckerProduct forms \(\mathbf{I}_{100} \otimes \boldsymbol{\Sigma}\). The genotype factor is an IdentityMatrix, so it has no free parameters. All of the free parameters live in the environment factor.

  • ScalarMatrix supplies \(\mathbf{R} = \sigma^2 \mathbf{I}\). It could be omitted, since it is the default residual covariance, but it is written out here for clarity.

Parameter names and ordering¶

The free parameters are ordered \([\boldsymbol{\theta}_Z, \boldsymbol{\theta}_G, \boldsymbol{\theta}_R]\). Here \(\boldsymbol{\theta}_Z\) is empty, so the first parameters belong to the random-effect covariance and the last one to the residual.

The names follow the paths of the covariance tree:

  • G/environment/factors/loadings/L_i_j is the loading of environment \(i\) on factor \(j\).

  • G/environment/uniqueness/sigma^2_j is the uniqueness \(\psi_j\).

  • R/sigma^2 is the residual variance.

The loadings are unconstrained. The uniquenesses and the residual variance are parameterised on the log-variance scale, \(\psi_j = \exp(2\theta)\) and \(\sigma^2 = \exp(2\theta)\), so a free value of zero corresponds to a variance of one. In total the model has \(11 + 6 + 1 = 18\) free parameters.

Recovery of the genotype-by-environment effects¶

The random-effect predictions can be obtained from blup_per_term(), which returns predictions keyed by term name. Here, there is a single term, “genotype”. Comparing these predictions with the generating effects in the genetic column assesses the fit at the individual genotype-by-environment level:

genetic = torch.tensor(fa_met.drop_duplicates(["genotype", "environment"])["genetic"].values)

blup = reml.blup_per_term()["g_by_e"]

torch.corrcoef(torch.stack([genetic, blup]))[0, 1]

tensor(0.9361)

(blup - genetic).pow(2).mean().sqrt()

tensor(0.3777)

The correlation is high, but the root mean squared error remains nonzero because the BLUPs are shrunk towards zero relative to the generating effects and are affected by estimation error in the covariance parameters.

Choosing the number of factors¶

In practice, \(k\) is unknown. A simple approach is to fit the model with \(k = 1, 2, 3\) and compare the restricted log-likelihoods. Since the fixed-effects structure is identical across fits, the AIC is \(-2\ell_R + 2p\), where \(p\) is the number of covariance parameters.

def fit_fa(k):
    G = KroneckerProduct(
        genotype=IdentityMatrix(genotype),
        environment=Sum(
            factors=Gram(
                LowerTriangularMatrix(environment, k),
                gram_type="xxt",
            ),
            uniqueness=DiagonalMatrix(environment),
        ),
    )
    model = MixedModelREML(g_by_e=(Z, G), R=ScalarMatrix(len(y)))
    names_k, _ = model.optimize(y, X, armijo_trials=5, fallback_eta=0.1)
    loglik_k = model.loglik()[0].item()
    p_k = len(names_k)
    return p_k, loglik_k, -2 * loglik_k + 2 * p_k

for k_k in (1, 2, 3):
    p_k, loglik_k, aic_k = fit_fa(k_k)
    print(f"k = {k_k}: p = {p_k}, loglik = {loglik_k:.3f}, AIC = {aic_k:.3f}")

k = 1: p = 13, loglik = -448.071, AIC = 922.143

k = 2: p = 18, loglik = -433.710, AIC = 903.421

k = 3: p = 22, loglik = -432.292, AIC = 908.584

AIC prefers two factors here, which is consistent with the generating model.

An unbalanced design¶

The trial above is balanced by construction, with every genotype appearing in every environment and two replicates per cell. Real multi-environment trials rarely have such a complete structure. Genotypes enter and leave testing at different sites, resulting in a ragged pattern of observed cells and different numbers of genotypes across environments. In this second part, cells are removed from the simulated trial while retaining both replicates in every remaining cell. Each genotype is grown in three of the six environments, selected at random using a fixed seed to ensure reproducibility.

Removing cells changes only the data. The model, parameterisation and number of free parameters remain the same as in the first part. The difference lies in how much information the data provide about those parameters.

The unbalanced trial¶

    missing[genotype] = {env_levels[i] for i in picks.tolist()}

keep = [

unbalanced = fa_met[keep].reset_index(drop=True)

Recovery of the genotype-by-environment effects¶

The practical reason for fitting the covariance is to predict the cells that were not observed. The BLUPs of the 600 cell effects are

blup_u = model_u.blup_per_term()["genotype"]
seen = (Z_u() != 0).any(dim=0)

seen marks the 300 cells that have observations.

def corr(x, y):
    return torch.corrcoef(torch.stack([x, y]))[0, 1]

def rmse(x, y):
    return (x - y).pow(2).mean().sqrt()

The observed cells are predicted as well as before. The unobserved cells are not simply left at zero. Their BLUPs are given by

\[\text{BLUP} = \mathbf{G}\mathbf{Z}^\top\mathbf{V}^{-1}\mathbf{r},\]

and the rows of \(\mathbf{G}\) corresponding to unobserved cells are correlated with those of the same genotype’s observed cells. Through \(\boldsymbol{\Sigma}\), the model therefore borrows information from the environments where the genotype was grown. The resulting predictions have a correlation of 0.50 with the generating effects and an RMSE of 0.89.

Two factors limit their accuracy. First, the covariance is estimated, so the prediction weights are estimated rather than known. Second, the observed effects are themselves shrunk, providing a shrunken basis for predicting the missing cells. The standard deviation of the unobserved BLUPs is 0.60, compared with 1.00 for the generating values. This shrinkage pulls predictions towards the mean, under-predicting good genotypes and over-predicting poor ones.

Choosing the number of factors¶

The comparison of the previous section has to be repeated on the reduced data:

def fit_fa_u(k):
    G = KroneckerProduct(
        genotype=IdentityMatrix(gen_levels),
        environment=Sum(
            factors=Gram(
                LowerTriangularMatrix(env_levels, k),
                gram_type="xxt",
            ),
            uniqueness=DiagonalMatrix(env_levels),
        ),
    )
    model = MixedModelREML(genotype=(Z_u, G), R=ScalarMatrix(len(y_u)))
    names_k, _ = model.optimize(y_u, X_u, armijo_trials=5, fallback_eta=0.1)
    loglik_k = model.loglik()[0].item()
    p_k = len(names_k)
    return p_k, loglik_k, -2 * loglik_k + 2 * p_k

for k_k in (1, 2, 3):
    p_k, loglik_k, aic_k = fit_fa_u(k_k)
    print(f"k = {k_k}: p = {p_k}, loglik = {loglik_k:.3f}, AIC = {aic_k:.3f}")

k = 1: p = 13, loglik = -270.979, AIC = 567.959

k = 2: p = 18, loglik = -267.277, AIC = 570.555

k = 3: p = 22, loglik = -267.017, AIC = 578.035

AIC now favours one factor, 568.0 compared with 570.6 for two factors, reversing the result from the balanced analysis. Although the covariance is still recovered, there is little evidence for the second factor. The \(k=2\) fit also had to push one uniqueness to zero to accommodate it.

A difference of 2.6 provides only weak evidence, and this is a simulated trial whose true number of factors is two. The conclusion is not that the model has one factor, but that 300 observed cells provide too little information to distinguish between the two.
