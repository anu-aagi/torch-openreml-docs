torch_openreml.MixedModelREML¶

class torch_openreml.MixedModelREML(*args, R=None, method='auto', **kwargs)[source]¶

Bases: object

REML estimator for a structured linear mixed model.

The model is specified by zero or more random-effect terms and one residual term, supplied with the keyword R. A random-effect term is a (design, covariance) pair, where design is the incidence matrix \(\symbf{Z}_i(\boldsymbol{\theta})\), either a fixed tensor or a Matrix — possibly parameterised, in which case its free parameters are part of \(\boldsymbol{\theta}\) — and covariance is the Matrix for \(\symbf{G}_i\), or a fixed two-dimensional tensor for a parameter-free \(\symbf{G}_i\). The residual term is a single Matrix for \(\symbf{R}\), or a fixed two-dimensional tensor, which is wrapped in a KnownMatrix. When R is omitted it defaults to \(\sigma^2\symbf{I}\), with the dimension inferred from the random-effect design.

The constructor builds the composite marginal covariance

\[\symbf{V}(\boldsymbol{\theta}) = \symbf{R}(\boldsymbol{\theta}) + \symbf{Z}(\boldsymbol{\theta}) \symbf{G}(\boldsymbol{\theta}) \symbf{Z}(\boldsymbol{\theta})^\top,\]

with \(\symbf{Z}(\boldsymbol{\theta})\) the column-wise augmentation of the \(\symbf{Z}_i(\boldsymbol{\theta})\) and \(\symbf{G}(\boldsymbol{\theta})\) their block-diagonal combination. Score and average-information evaluation is then dispatched to a numerical method:

  • CForm for one or more random-effect blocks, with fixed or parameterised designs and dense, invertible \(\symbf{G}\) and \(\symbf{R}\);

  • Marginal for the general \(\symbf{V}\)-based case, including multiple random-effect blocks and approximate traces.

The method is selected by method, which is "auto" by default. With "auto" CForm is used when the model is eligible for it and Marginal otherwise; if an eligible CForm fails, a warning is emitted and Marginal is used instead. "cform" and "marginal" force a particular method. A configured CForm or Marginal instance may also be supplied, for example Marginal(trace_approx="auto"); the instance is stored on the model and reused across steps.

Free covariance parameters are ordered as [free_params_Z, free_params_G, free_params_R]. A block with no free parameters occupies a zero-length slice. The fitted model keeps the optimisation trace in history; use optimize() for fitting and blue(), blup(), blup_per_term(), build_params(), marginal_predict(), marginal_residual(), predict(), residual() and loglik() for post-fitting quantities.

Parameters:

  • *args – Random-effect (design, covariance) pairs.

  • R – Residual covariance \(\symbf{R}\), either a Matrix or a fixed two-dimensional tensor, which is wrapped in a KnownMatrix. Defaults to None, in which case \(\sigma^2\symbf{I}\) is used, i.e. a ScalarMatrix whose dimension is inferred from the random-effect design. R must be supplied explicitly when the model has no random-effect terms, because the dimension cannot then be inferred.

  • method – Numerical method used for score and average-information evaluation. "auto" (the default) uses CForm when the model is eligible for it and Marginal otherwise; if an eligible CForm fails, a warning is emitted and Marginal is used instead. "cform" and "marginal" force one method; a configured CForm or Marginal instance is stored on the model and reused across steps. Any other value behaves like "auto".

  • **kwargs – Named random-effect terms, each a (design, covariance) pair. Term names must be unique, and no term may be named R (or method).

Raises:

  • TypeError – If a positional argument is not a (design,     covariance) pair, a design is not a tensor or Matrix, or a covariance is not a Matrix or a fixed two-dimensional tensor.

  • ValueError – If R is omitted and the model has no random-effect terms, a term has the wrong length, a random-effect covariance tensor is not two-dimensional, a term name is duplicated, or the marginal covariance has no free parameters.

Example:

import torch
from torch_openreml import MixedModelREML
from torch_openreml.covariance import ScalarMatrix, DummyMatrix

n, p = 100, 3
y = torch.randn(n)
x = torch.randn(n, p)
group = [f"g{i % 20}" for i in range(n)]
z = DummyMatrix(group)
reml = MixedModelREML((z, ScalarMatrix(20)), R=ScalarMatrix(n))
free_param_names, free_params_hat = reml.optimize(y, x, torch.tensor([0.0, 0.0]), verbose=1)

cov_blue(x=None, free_params=None)[source]¶

Covariance matrix of the fixed-effect BLUE.

The BLUE is \(\hat{\boldsymbol{\beta}} = (\symbf{X}^{\top}\symbf{V}^{-1}\symbf{X})^{-1} \symbf{X}^{\top}\symbf{V}^{-1}\symbf{y}\), so its covariance is

\[\operatorname{Var}(\hat{\boldsymbol{\beta}}) = \left(\symbf{X}^{\top}\symbf{V}^{-1}\symbf{X}\right)^{-1},\]

the C11 block of the inverse C-form matrix. The covariance does not depend on the response \(\symbf{y}\), only on the design and the covariance parameters.

Parameters:

  • x (torch.Tensor, optional) – Fixed-effect design matrix of shape (n, p). Default: the design stored by optimize().

  • free_params (torch.Tensor or str, optional) – Covariance parameters, or "last" / "best" to select a fitted iterate. If omitted, the last fitted parameters are used. A ValueError is raised when no fit exists.

Returns:

BLUE covariance matrix of shape (p, p).

torch.Tensor

c_inverse_blocks(x=None, free_params=None)[source]¶

Blocks of the inverse of the mixed-model coefficient matrix.

With the coefficient matrix

\[\begin{split}\symbf{C} = \begin{pmatrix} \symbf{X}^\top\symbf{R}^{-1}\symbf{X} & \symbf{X}^\top\symbf{R}^{-1}\symbf{Z} \\ \symbf{Z}^\top\symbf{R}^{-1}\symbf{X} & \symbf{Z}^\top\symbf{R}^{-1}\symbf{Z} + \symbf{G}^{-1} \end{pmatrix},\end{split}\]

the method returns the blocks of \(\symbf{C}^{-1}\). Block \(\symbf{C}_{11} = (\symbf{X}^\top\symbf{V}^{-1}\symbf{X})^{-1}\) is the covariance of the fixed-effect estimates and \(\symbf{C}_{22}\) is the prediction-error covariance of the random-effect predictions.

Parameters:

  • x (torch.Tensor, optional) – Fixed-effect design matrix of shape (n, p). Default: the design stored by optimize().

  • free_params (torch.Tensor or str, optional) – Covariance parameters, or "last" / "best" to select a fitted iterate. If omitted, the last fitted parameters are used. A ValueError is raised when no fit exists.

Returns:

(c11, c12, c21, c22), the blocks of \(\symbf{C}^{-1}\), with shapes (p, p), (p, q), (q, p) and (q, q).

Return type:

tuple

Raises:

RuntimeError – If the model has no random-effect term or no free parameters.

Example

import torch
from torch_openreml import MixedModelREML
from torch_openreml.covariance import DummyMatrix, ScalarMatrix

torch.manual_seed(0)
n = 30
x = torch.randn(n, 2)
z = DummyMatrix([f"g{i % 5}" for i in range(n)])
reml = MixedModelREML((z, ScalarMatrix(5)), R=ScalarMatrix(n))
c11, c12, c21, c22 = reml.c_inverse_blocks(x, torch.zeros(2))
print(c11.shape, c12.shape, c21.shape, c22.shape)

torch.Size([2, 2]) torch.Size([2, 5]) torch.Size([5, 2]) torch.Size([5, 5])

cov_blup(x=None, free_params=None)[source]¶

Covariance matrix of the BLUPs.

The BLUP is \(\hat{\symbf{b}} = \symbf{G}\symbf{Z}^{\top}\symbf{P}\symbf{y}\), so its covariance is

\[\operatorname{Var}(\hat{\symbf{b}}) = \symbf{G}\symbf{Z}^{\top}\symbf{P}\symbf{Z}\symbf{G},\]

with \(\symbf{P} = \symbf{V}^{-1} - \symbf{V}^{-1}\symbf{X}(\symbf{X}^{\top}\symbf{V}^{-1}\symbf{X})^{-1}\symbf{X}^{\top}\symbf{V}^{-1}\). This is equal to \(\symbf{G} - \symbf{C}_{22}\), but it only requires \(\symbf{V}\) to be invertible, not \(\symbf{G}\). The covariance does not depend on the response \(\symbf{y}\), only on the design and the covariance parameters.

Parameters:

  • x (torch.Tensor, optional) – Fixed-effect design matrix of shape (n, p). Default: the design stored by optimize().

  • free_params (torch.Tensor or str, optional) – Covariance parameters in model order, or "last" / "best" to select a fitted iterate. If omitted, the last fitted parameters are used. A ValueError is raised when no fit exists.

Returns:

BLUP covariance matrix of shape (q, q).

Return type:

torch.Tensor

Raises:

ValueError – If the model has no random-effect terms, so there is no random-effect vector to predict.

predict_new(x, z=None, free_params=None)[source]¶

Predictions at new rows from already-built design matrices.

This method only consumes materialised tensors: it does not encode factors or construct the incidence matrix of new data. Build x and each z block in the training column order, then pass them here. A single new observation is just a one-row batch. For a DummyMatrix block, DummyMatrix.transform does that encoding onto the training columns. The random-effect contribution uses the BLUPs computed from the stored training data by blup().

Parameters:

  • x (torch.Tensor) – Fixed-effect design matrix of shape (n_new, p) with at least one row. It must have the same columns as the training design, in the same order.

  • z (torch.Tensor, list, dict or None, optional) – Incidence matrix of new data. Either a full tensor of shape (n_new, q), a list with one (n_new, q_i) block per random-effect term, or a dict keyed by term name. Terms omitted from a dict contribute zero, so the caller chooses the active terms by what it supplies. None gives the population prediction, ignoring the random effects. Default: None.

  • free_params (torch.Tensor or str, optional) – Covariance parameters in model order, or "last" / "best" to select a fitted iterate. If omitted, the last fitted parameters are used.

Returns:

Predictions of shape (n_new,).

Return type:

torch.Tensor

Raises:

optimize(y, x, init_values=None, max_iter=200, lb=-inf, ub=inf, verbose=0, check_update=True, check_loglik=True, tol_update=0.0001, tol_loglik=0.0001, armijo_trials=30, armijo_c=0.0001, eta_shrink=0.5, eta_max=1.0, eta_min=1e-10, fallback_eta=0.001, armijo_slack=1e-07)[source]¶

Run the AI-REML optimisation loop with Armijo backtracking.

The AI direction is always delta = AI^{-1} score. A backtracking line search starts from eta_max and multiplies it by eta_shrink after each rejected candidate. eta_max is also the value restored after every accepted or fallback step, so it acts as the maximum step length. If the line search cannot find a finite candidate that sufficiently increases the log-likelihood, one small gradient-ascent step is taken instead.

A candidate is accepted when

\[\ell_{\mathrm{new}} \geq \ell + c \, \eta \, \symbf{s}^\top\boldsymbol{\delta} - \epsilon \max(1, |\ell|),\]

where c = armijo_c and epsilon = armijo_slack. The last term is a small numerical slack; set armijo_slack=0 for strict Armijo.

Any score history kept by the selected Marginal instance for trace_approx="auto" is reset before the first iteration.

Parameters:

  • y (torch.Tensor) – Response vector of shape (n,).

  • x (torch.Tensor) – Fixed-effect design matrix of shape (n, p).

  • init_values (torch.Tensor, optional) – Initial covariance parameters. When omitted, the model’s default parameters are used.

  • max_iter (int, optional) – Maximum number of AI iterations. Default: 200.

  • lb (float, optional) – Lower bound for parameters. Default: -torch.inf.

  • ub (float, optional) – Upper bound for parameters. Default: torch.inf.

  • verbose (int, optional) – If positive, print one line per iteration. Default: 0.

  • check_update (bool, optional) – Whether the maximum absolute parameter update participates in convergence. Default: True.

  • check_loglik (bool, optional) – Whether the log-likelihood change participates in convergence. Default: True.

  • tol_update (float, optional) – Convergence tolerance for the maximum absolute parameter update. Default: 1e-4.

  • tol_loglik (float, optional) – Convergence tolerance for the log-likelihood change. Default: 1e-4.

  • armijo_trials (int, optional) – Maximum number of backtracking candidates. Default: 30.

  • armijo_c (float, optional) – Armijo sufficient-increase constant. Default: 1e-4.

  • eta_shrink (float, optional) – Multiplier applied after each rejected candidate. Default: 0.5.

  • eta_max (float, optional) – Initial and restored step length. Default: 1.0.

  • eta_min (float, optional) – Smallest step length tried. Default: 1e-10.

  • fallback_eta (float, optional) – Step length for the normalized gradient fallback. Default: 1e-3.

  • armijo_slack (float, optional) – Relative numerical slack in the Armijo test. Default: 1e-7.

Returns:

(free_param_names, free_params), where free_param_names is the list of namespaced covariance parameter names and free_params is the final covariance-parameter tensor in that order.

Return type:

tuple

Notes

The optimisation trace is stored in history with keys "free_params", "loglik", "score", "ai", "delta", "update", "eta", "accepted" and "method". "accepted" is True only for a line-search-accepted Newton step; gradient fallback steps are recorded with False. "method" records, for each iteration, the method that produced the AI step, either "cform" or "marginal". The response y and design x are stored on the instance and are reused by the post-estimation methods (blue(), blup(), predict(), residual(), loglik(), and the covariance methods) when called without them.
